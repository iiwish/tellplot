# G009 TellPlot 开源介绍视频 Spec

## Metadata

- Feature ID: `015-launch-video`
- Goal ID: `G009`
- Version: 1.4.0
- Status: Confirmed
- Last updated: 2026-08-02
- Approval: 用户明确批准使用真实产品录制、Remotion 合成与 Qwen3-TTS 旁白完成视频制作，并提供最终旁白 WAV

## Objective

制作一支以创作者真实经历为叙事核心、以 TellPlot 真实交互为产品证据的开源项目介绍视频。主片跟随用户
提供的 62.969 秒中文旁白，不把产品演示替换为虚构 UI。验片中发现的拖拽反馈缺口在框架无关 editor
runtime 内修复，不改变公共 API、schema、官网或包布局。

## Requirements

### VIDEO-FR-001 首屏抓力与创作者叙事

前 2 秒同时出现问题钩子、真实图表和已就位的可见指针；真实拖拽在对应旁白关键词进入时发生，前 8 秒
完成拖拽回报，前 12 秒完成框选分组并建立 TellPlot 品牌。旁白使用第一人称说明财务分析需求、早期瀑布图
原型和系统化重构动机。

### VIDEO-FR-002 真实产品证据

画面必须来自当前 TellPlot production build 或其确定性浏览器录制，覆盖直接排序、框选分组、折叠、
撤销、结构/视图状态和瀑布图，并通过真实官网画面清楚表达柱状图、条形图支持。不得用 Remotion 重画或
伪造核心产品交互，也不得为证明图表家族而快速切换图表状态。

### VIDEO-FR-003 可重复制作工程

仓库新增 private `@tellplot/video` workspace，以 Remotion 4.0.503 编排真实录屏、字幕、品牌排版、镜头运动
和最终输出。视频工程不得被公共 `tellplot` 包依赖或进入 npm tarball。

### VIDEO-FR-004 旁白、字幕与声音

使用用户批准并在本地提供的 Qwen3-TTS WAV 作为旁白源。制作工程保存可追踪副本，
按真实波形和语句对齐字幕，保持清晰语音优先；不得把金额、个人凭据或未公开业务数据发送到外部服务。

### VIDEO-FR-005 交付规格

交付 3840x2160、30fps、H.264/AAC 的 16:9 主片、UTF-8 SRT 字幕、3840x2160 封面 PNG 和可复现的
本地渲染命令。最终媒体输出保存在忽略目录，不进入 Git 历史；交付目录只保留横版终片。

### VIDEO-FR-006 产品边界准确

视频只表达当前稳定能力，不宣称任意 G2 配置、通用插件框架或尚未实现的图表类型。Remotion 只属于制作
工具链，不接管 TellPlot 图表动画，也不成为公共或生产依赖。

## Non-Functional Requirements

- VIDEO-NFR-001：主片重要信息在 45 秒前完成；产品叙事段不叠加旁白、字幕之外的解释性标题。
- VIDEO-NFR-002：字幕在 16:9 安全区域内保持可读，不遮挡关键图表或交互目标。
- VIDEO-NFR-003：真实录屏无浏览器外壳、通知、账号、凭据、调试 UI 或光标漂移。
- VIDEO-NFR-004：旁白无削波，最终音轨峰值不高于 -1 dBFS，主观响度稳定，开头交互声不掩盖人声。
- VIDEO-NFR-005：4K 主片通过抽帧、黑帧、时长、分辨率、编码和音画同步检查。
- VIDEO-NFR-006：Remotion 当前许可仅用于已批准的个人/不超过三人的开源制作；团队或使用方式变化时重新审计。

### VIDEO-FR-007 可见指针与操作因果

所有鼠标驱动的真实产品镜头必须显示清晰指针，并在按下、拖拽、释放和点击时提供克制的状态反馈。指针由
录制脚本注入 production page，仅作为录屏层，不修改产品源码；指针必须跟随真实 Playwright mouse event，
不得由后期猜测路径。

### VIDEO-FR-008 连续编辑叙事

真实产品画面是全片主视觉。0 至 50.4 秒使用同一次浏览器会话的连续编辑长镜头，不因旁白段落更换背景、
裁切方向或图表类型；解释由旁白与字幕承担，不额外叠加 editorial 标题、规则线、卡片或流程图。50.4 秒
使用一次真实官网静态画面证明图表家族，56.86 秒进入最终邀请页；全片主视觉切点最多两个。

### VIDEO-FR-009 语音、动作与切点同步

字幕边界以 WAV 波形的实际语音区间为准。拖拽、框选、撤销、导出和 ViewSpec 的动作起点必须与对应旁白
关键词在 0.12 秒内对齐；图表家族证明和最终邀请的切点落在自然停顿，动作结果在对应语句结束前可见。

### VIDEO-FR-010 真实拖拽反馈与分组节奏

图表拖拽必须显示与真实 G2 scene mark 尺寸、方向和语义颜色一致的柱形预览。预览按指针相对按下位置的
位移逐事件直接更新，不使用弹簧、插值或猜测边界；指针、柱形预览和落点指示必须同时可见。框选分组依次
保留选区完成、对话框出现、逐字输入名称和创建结果四个可辨识阶段，不得把输入与提交压缩成闪现。

- VIDEO-NFR-007：仅两个主视觉转场动画 `transform` 或 `opacity`，单次进入控制在 6-12 帧；不使用无目的
  弹跳、连续纯渐隐、镜头推拉或长时间整页说明标题。
- VIDEO-NFR-008：拖拽预览只更新合成友好的 `transform`，直接跟随指针且可中断；横版长镜头使用一个
  固定焦点，分组对话框的字段与主操作按钮不得被裁切。

### VIDEO-FR-011 4K 横版品牌终稿

真实浏览器录制使用 3840x2160 物理画布、1920x1080 逻辑布局和 Chromium 2x page scale，保证录制流完整
铺满 4K 画面并保持既有交互坐标语义。全片左上角固定显示克制的 `TellPlot.com` 品牌水印，水印不得遮挡
产品操作、字幕或状态反馈。封面使用真实编辑器画面、TellPlot 品牌、项目定位标题和官网地址，不使用虚构
产品 UI；竖版视频不属于当前交付。

- VIDEO-NFR-009：水印固定、无动画、具备浅色和深色画面的稳定对比度；4K 输出不得包含低分辨率内容区、
  灰色留白或只占画布局部的录屏。

## Success Criteria

- VIDEO-SC-001：真实交互素材可由脚本重新录制，Remotion 工程可从 clean install 重新渲染。
- VIDEO-SC-002：主片完整覆盖 VIDEO-FR-001 至 006，时长与旁白匹配，无空白或中断画面。
- VIDEO-SC-003：4K 16:9 主片、SRT 和 4K 封面均生成并可本地播放或查看，输出目录无竖版终片。
- VIDEO-SC-004：至少在开头、中段、结尾及每次关键转场抽帧复核，无文字遮挡、裁切或非预期黑帧。
- VIDEO-SC-005：`format`、`lint`、`typecheck`、视频单元检查、Remotion render 与 artifact validator 通过。
- VIDEO-SC-006：无 unresolved Critical、High 或 Medium finding。
- VIDEO-SC-007：真实录屏指针可见且与实际 mouse event 同步，关键动作 cue 自动测试误差不超过 0.12 秒。
- VIDEO-SC-008：motion review 不存在 feel-breaking、PPT 式连续标题页或可删除的无目的动画；产品段
  editorial overlay 数为 0，主视觉切点不超过 2，图表家族证明不切换图表状态。
- VIDEO-SC-009：单元测试验证拖拽预览使用 renderer scene bounds 与当前 palette，并按真实指针 delta 移动；
  时间合同验证拖拽、框选完成、名称输入和创建之间存在可读停留；4K 横版关键帧验证动作及完整对话框可见。
- VIDEO-SC-010：媒体探测确认主片和封面均为 3840x2160；关键帧确认水印固定可读、录屏铺满画面且封面
  使用真实产品画面。

## Non-Goals

- 修改本次拖拽反馈以外的 TellPlot 产品能力、公共 API、schema、官网生产内容或 npm 包。
- 建设在线视频编辑器、批量渲染服务、云端转码或通用媒体框架。
- 生成虚构客户、虚构业务数据、真人形象或未经许可的音乐。
- 在本目标中发布社交平台帖子、创建 Git tag、npm release 或远程部署。
- 制作或交付 9:16 竖版视频。
