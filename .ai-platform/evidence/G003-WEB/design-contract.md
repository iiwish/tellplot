# G003-WEB 官网与工作台体验合同

## 目标

- 首页以 `01 经营变动瀑布图` 作为确定性首屏，示例编号、默认内容和用户预期保持一致。
- 用户从官网进入工作台后，可以在五个公开示例之间切换，无需记忆 query string 或返回示例页。
- 当前示例继续由 URL 表达，刷新、分享和浏览器前进后退都能恢复同一图表。

## 设计方向

- **体验主线**：同一份编号示例目录贯穿首页、示例中心与工作台。
- **工作台定位**：保持安静、紧凑的操作界面；示例切换属于文件栏上下文，而不是新增营销区块或卡片。
- **标志性动作**：编号加图表名称的原生选择器，让用户始终知道正在编辑哪个公开示例。
- **视觉继承**：沿用现有白色文件栏、蓝色主操作和 5px 至 8px 圆角，不引入新色板、新依赖或整页重构。

## 交互合同

- 首页默认选中目录第一项 `waterfall`，按钮具有 `aria-pressed="true"`。
- 工作台选择器从当前 URL 推导选中项；五个选项使用 `01` 至 `05` 的稳定编号。
- 切换后通过应用内部导航进入目录中的 canonical `workbenchHref`，工作台重建对应 config 与 ViewSpec。
- 当前配置或 ViewSpec 已被编辑时，切换前提示会重置当前编辑；取消则保留当前示例和焦点。
- 测试或诊断 fixture 不伪装成公开示例，选择器显示只读的“当前测试数据”占位项。

## 响应式与无障碍

- 桌面显示“示例”标签、编号和完整短标题；窄屏隐藏可省略标签，但保留可读的 select accessible name。
- 文件栏控件尺寸稳定，不挤压导入、导出和状态反馈；超窄屏允许状态详情收敛而不产生横向溢出。
- 原生 select 支持键盘、触摸和系统辅助技术；焦点轮廓与既有工具按钮一致。

## 边界

- 不修改 `tellplot` 公共 API、schema、图表 runtime 或 npm artifact。
- 不建设通用图表注册系统；官网目录仍是 website-only catalog。
- 不新增依赖，不改变五个公开示例的 fixture contract。

## 验证

- Unit：默认示例、URL 到示例映射、版本标识和 canonical fixture。
- E2E：首页默认 01、工作台切换、URL 持久化、dirty guard、移动端无溢出和可访问名称。
- Visual QA：桌面与 390px 移动端截图，检查文件栏、图表画布、选择器和既有操作无重叠。
